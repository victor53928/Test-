# 포트폴리오 리밸런싱 앱

산업군별 상장 주식(시가총액/매출/영업이익/거래량), 원자재, 채권 데이터를 추적하여
목표 자산배분(주식 50% / 원자재 30% / 채권 20%) 대비 리밸런싱을 돕는 개인용 로컬 앱.

## 추적 산업군
반도체, 방산, 조선, 에너지, 원전, 자율주행, 피지컬 AI, 화장품, 엔터테인먼트, 2차전지/배터리
(10개 산업군 전부 한국·미국·일본 대표주를 함께 추적)

## 개발 단계
- [x] Phase 1: 국내 주식 데이터 파이프라인 (네이버 증권 + DART) + 뷰어
- [x] Phase 2: 미국 대표주 통합 (yfinance)
- [x] Phase 3: 원자재/채권 데이터 통합 (yfinance)
- [x] Phase 4: 포트폴리오 수동 입력 + 리밸런싱 계산 엔진
- [ ] Phase 5: 대시보드 고도화

> **국내 주식 데이터는 pykrx(KRX 공식 데이터)를 우선 사용하고, 실패하면 네이버 증권
> 스크래핑(`app/naver_finance.py`)으로 자동 전환합니다** (`app/kr_data_source.py`가 이
> 전환을 담당). pykrx는 `KRX_ID`/`KRX_PW` 환경변수 없이 익명 세션으로도 동작합니다 —
> import 시 뜨는 "KRX 로그인 실패" 메시지는 정보성 출력일 뿐 실제 오류가 아닙니다.
> 네이버 증권 경로는 공식 API가 아니라 페이지 구조에 의존하므로, pykrx가 실패해서
> 네이버로 넘어간 경우 네이버가 페이지를 개편하면 일부 항목 파싱이 깨질 수 있습니다 —
> 값이 이상하거나 안 나오면 이슈로 알려주세요.

## 설치

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

`.env`에 DART Open API 키를 채워넣으세요 (무료, https://opendart.fss.or.kr 에서 발급).
DART 키가 없어도 시가총액/거래량 수집은 정상 동작하지만, 매출/영업이익 수집과 **한국 종목을
이름만으로 추가하는 기능**(산업군별/관심종목 페이지)은 DART 키가 반드시 있어야 합니다
(종목명→종목코드 변환에 DART의 기업 목록을 사용하기 때문). 키가 없으면 추가 시도할 때
화면에 안내 메시지가 뜹니다.

## 데이터 수집

```bash
python -m app.collectors.run_collection
```

국내 10개 산업군 대표 종목과 전 산업군의 일본·미국 대표주에 대해 최근 10년치
시가총액/거래량과 최근 2개년 분기별 매출/영업이익,
주요 원자재(금/은/구리/WTI 원유)와 채권(미국 10년물 금리, TLT, 국내 국고채10년 ETF) 가격을
`data/portfolio.db` (SQLite)에 저장합니다.

> 한국/미국/일본 주식 모두 시가총액은 `종가 × 현재 발행주식수`로 근사합니다 (네이버 증권도
> yfinance와 마찬가지로 과거 시가총액을 날짜별로 직접 제공하지 않습니다). 자사주 매입/발행이
> 컸던 구간에서는 오차가 있을 수 있습니다. 10년치 데이터를 새로 수집하므로 최초 실행 시
> 기존보다 시간이 더 걸릴 수 있습니다.

  인터뷰 관련 기사를 매일경제/한국경제 우선으로 보여줍니다 (관심종목 페이지의 종목별
  뉴스와는 별개입니다).
- **산업군별 주식**: 산업군 블록(10개) → 시장 블록(한국/미국/일본, 해당 산업군에 있는 시장만
  표시) 순서로 클릭해서 선택합니다. 그 아래에서 그래프에 표시할 종목을 직접 고를 수 있고
  (다중 선택), 기간(1주일~10년)은 그래프 바로 아래에서 선택하며 선택 즉시 그래프에 반영됩니다.
  최신 종가/시가총액은 기간 선택과 무관하게 항상 가장 최근 거래일 기준으로 표시되고, "기준일자"
  컬럼에 그 값이 며칠자 데이터인지 표시됩니다. 배치로 수집된 한국 주식 데이터가 없거나 5일
  이상 오래됐으면 그 자리에서 (pykrx 우선, 실패 시 네이버 증권으로) 최근 30일치를 실시간
  재조회해서 표/그래프를 채웁니다 (그래도 실패하면 화면에 에러 메시지가 표시됩니다 — 전체
  10년 그래프를 보려면 배치 수집을 실행해야 합니다). 시가총액 그래프는 마우스를 올리면
  정확한 금액이 뜨고 각 종목 선 끝에
  최신 값이 라벨로 표시되며, 그 아래에 거래대금(종가×거래량 근사치) 추이 그래프도 있습니다.
  "종목 추가 / 삭제"는 페이지 맨 아래에 있고, 종목명만 입력해서 추가/삭제할 수 있습니다
  (추가한 종목은 그 자리에서 바로 시세/재무 데이터를 가져와 보여주고, 다음 배치 수집에도
  자동 포함됩니다).
- **원자재** / **채권**: 각각 별도 페이지로 분리되어 있으며, 종목/채권마다 개별 그래프로

  눌려 보이는 문제를 피하기 위함). 채권은 원화 채권/달러 채권으로도 나뉘어 표시되고, 미국

  보여줍니다 (두 값의 단위 차이가 커서 한 축에 그리면 금리 쪽이 납작하게 눌리기 때문).
  마찬가지로 기간 선택을 지원하고, 최신 가격은 기간 선택과 무관합니다.

> **10년치 그래프가 3개월까지만 바뀌고 그 이후(1년/3년/5년/10년)로는 그래프가 그대로인
> 경우**: 코드 버그가 아니라 로컬에 아직 짧은 기간의 데이터만 쌓여있기 때문입니다.
> `python -m app.collectors.run_collection`을 다시 실행해서 10년치 데이터를 채워주세요
> (기존 데이터는 덮어쓰지 않고 없는 날짜만 추가되므로 여러 번 실행해도 안전합니다).
- **관심종목**: 아래 "관심종목 뉴스 & 시세 대시보드" 섹션 참고.
- **종목 비교**: 원하는 종목을 종목명만으로 최대 5개까지 담아서 (시장/통화가 달라도 상관없이)
  비교합니다 — 가격 변화율, 시가총액 변화율(기간 시작일 대비 %, 미국/일본은 발행주식수가
  일정하다고 가정한 근사치), 거래량, 거래대금(종가×거래량 근사치) 그래프와, 연도별
  매출액/영업이익 막대그래프, 그리고 시가총액/PER/PBR/EPS/배당수익률/ROE/52주 최고·최저/
  평균거래량/Beta 지표를 한 표에 나란히 비교합니다.
- **산업군 비교**: 종목 하나하나가 아니라 산업군 전체 단위로 비교합니다. 산업군에 속한

  반도체 산업군과 방산 산업군 중 어디에 더 많은 돈이 들어왔는지" 같은 비교가 가능합니다.
  전체/한국/미국/일본 블록을 눌러 특정 시장만 따로 비교할 수 있고, 오늘 기준 산업군별
  거래대금 막대그래프, 국내/미국/일본 비중 그래프(전체 보기에서만 표시), 산업군 블록을
  여러 개 눌러서 복수 선택하는 기간별(1주일~10년) 거래대금 추이 그래프를 제공합니다.
  10개 산업군 모두 미국 대표주(피지컬 AI 산업군에는 Palantir·Microsoft·Alphabet·Meta 등
  AI 기업도 포함)를 갖추고 있습니다. 한국/미국/일본 블록을 선택하면 그 시장 통화(원화/
  달러/엔화)로 표시되고, 전체 보기는 통화를 맞춰야 비교가 가능하므로 원화로 환산해서
  보여줍니다. 1억 이상 금액은 "37조 1,000억원", "260억 달러"처럼 조/억 단위 한글
  표기로 보여줘서 큰 숫자도 한눈에 읽힙니다. 배치 수집
  (`python -m app.collectors.run_collection`)을 미리 해두면 훨씬 빠르게 뜨고 최대 10년치
  추이까지 볼 수 있습니다 — 안 해도 동작은 하지만 종목이 많아(현재 10개 산업군 약 70여
  종목) 처음 열 때 실시간 조회에 시간이 걸릴 수 있습니다.
- **포트폴리오** (맨 아래): 보유 종목(자산군/종목/수량)을 직접 입력하면 목표 자산배분
  (주식 50% / 원자재 30% / 채권 20%) 대비 현재 비중과 이탈도, 리밸런싱에 필요한 매수/매도
  금액을 확인할 수 있습니다.

모든 화면의 가격/금액 수치는 천 단위 구분 콤마와 통화 기호(₩/$/¥)로 표시됩니다. 시가총액·
거래대금·매출·영업이익처럼 1억 이상으로 커지기 쉬운 금액은 "37조 1,000억원", "260억 달러"
처럼 조(兆)/억(億) 단위 한글 표기로 보여줘서 큰 숫자도 한눈에 읽힙니다 (1억 미만은 기존
방식 그대로 ₩/$/¥ + 콤마).

> 국내 종목은 원화(₩), 미국 종목·원자재·TLT는 달러($), 일본 종목은 엔화(¥)로 가격이 매겨져
> 있어 `.env`의 `USD_KRW_RATE` / `JPY_KRW_RATE` 값으로 환산해 하나의 포트폴리오로 합산합니다.
> 실시간 환율이 아니라 수동 설정값이므로 실제 환율과 크게 벌어지면 `.env`에서 값을 갱신해주세요.

## 관심종목 뉴스 & 시세 대시보드

왼쪽 사이드바의 "관심종목" 페이지에서 내가 원하는 종목(국내 코스피/코스닥, 미국, 일본)을
**종목명만 입력하면** 종목코드를 자동으로 찾아 등록합니다 (한국은 DART 기업 목록 기준으로
정확하게, 미국/일본은 yfinance 검색 기준으로 best-effort). 종목코드는 화면에 따로 노출되지
않고 내부적으로만 쓰입니다 — 자동으로 못 찾으면 정확한 회사명으로 다시 시도해야 합니다.
등록하면 종목별로 위에서 아래로:

등록된 종목은 **한국 주식 / 미국 주식 / 일본 주식** 그룹으로 나뉜 작은 블록으로 표시되고,
블록을 클릭하면 그 종목의 상세 정보가 아래에 나타납니다.

- 시세: 한국은 종가/시가총액/거래량, 미국·일본은 현재가. 가격/거래량 그래프는 화면 전체
  너비로 크게 표시되고, 기준일자와 기간 선택(그래프 바로 위)이 함께 있습니다. 한국
  종목(코스피/코스닥)은 코스피 지수를 함께 겹쳐서 보여줍니다 — 왼쪽 축이 코스피, 오른쪽
  축이 그 종목 가격이라 서로 스케일이 달라도(지수 vs 원화 가격) 추이를 바로 비교할 수
  있습니다.
- 재무 상황 (Yahoo Finance 스타일): 시가총액, PER, PBR, EPS, BPS, 배당수익률, 주당배당금,
  ROE, 52주 최고/최저, 평균거래량, Beta, 그리고 연도별 매출/영업이익 막대그래프 (한국은
  DART 기준 최대 10개년, 미국·일본은 yfinance가 제공하는 범위만큼 — 보통 4개년 안팎으로,
  데이터 제공처의 한계입니다)
- 뉴스: 매일경제·한국경제 기사를 우선 표시하고, 해당 키워드로 두 매체 기사가 없으면
  전체 뉴스로 자동 대체해서 보여줍니다 (뉴스가 아예 안 뜨는 경우를 피하기 위함)

뉴스 검색 키워드는 기본적으로 종목명을 사용하며, 원하면 종목별로 다른 키워드를 지정할 수 있습니다.

### 네이버 API 키 발급

1. https://developers.naver.com/apps 에서 애플리케이션을 등록합니다.
2. 사용 API에서 "검색"을 추가합니다 (뉴스 검색에 사용, 무료).
3. 발급된 Client ID / Client Secret을 `.env`의 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`에 채웁니다.

키가 없어도 앱은 실행되지만, 관심종목 페이지의 뉴스 영역에는 경고 메시지만 표시됩니다.
매출/영업이익 추이(한국)는 DART_API_KEY가 없으면 표시되지 않습니다.

### 한계 (v1)

- **시세는 실시간 스트리밍이 아닙니다.** 국내 종목은 pykrx(실패 시 네이버 증권), 미국·일본
  종목은 yfinance로 조회한 최신 종가/시세를 60초 캐시로 새로고침합니다.
- **관심종목 목록은 재배포 시 초기화됩니다.** SQLite 파일(`data/portfolio.db`)은 저장소에
  커밋되지 않으므로(`.gitignore`), Streamlit Community Cloud에 새로 `git push`할 때마다
  컨테이너가 새로 빌드되며 관심종목 목록(및 산업군별로 추가한 종목)이 사라집니다. 배포 중 앱을
  계속 쓰는 동안은 유지되지만, 코드를 업데이트할 때마다 다시 등록해야 합니다. 지속적으로
  보관하려면 추후 외부 DB(예: 호스팅형 SQLite/Postgres) 연동이 필요합니다.

## 배포 (Streamlit Community Cloud)

1. 이 저장소를 GitHub에 push합니다.
2. https://share.streamlit.io 에서 "New app"을 선택하고, 저장소/브랜치를 연결한 뒤
   Main file path에 `app/dashboard.py`를 지정합니다.
3. "Advanced settings" → "Secrets"에 아래와 같이 입력합니다 (TOML 형식):

   ```toml
   NAVER_CLIENT_ID = "..."
   NAVER_CLIENT_SECRET = "..."
   DART_API_KEY = "..."
   USD_KRW_RATE = "1400"
   JPY_KRW_RATE = "9.3"
   ```

4. 배포하면 공개 URL이 생성됩니다. 이후 `git push`할 때마다 자동 재배포됩니다
   (단, 위 "한계" 항목에서 설명한 대로 관심종목 목록은 그때마다 초기화됩니다).
